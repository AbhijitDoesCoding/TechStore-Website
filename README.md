
# 🛍️ TechStore — Modern E-Commerce Web App

TechStore is a fully interactive, responsive, and feature-rich e-commerce web application built using **HTML, CSS, and JavaScript.** It includes product browsing, live search, filtering, sorting, cart management, checkout flow, and modal-based order confirmation — all without a backend.

---

## ✨ Features

✔️ **Product Catalog** displayed in grid or list view
✔️ **Live Search Filtering** as you type
✔️ **Category Filtering** (Electronics, Accessories, Wearables, etc.)
✔️ **Price Range Slider** to limit results
✔️ **Sorting Options** (Price, Name, Default)
✔️ **Add to Cart Functionality** with item quantity control
✔️ **Persistent Cart Badge** showing items count
✔️ **Responsive Layout** for desktop, tablet, and mobile
✔️ **Sidebar Shopping Cart** with order summary
✔️ **Checkout Modal** with user info, payment options, and validation
✔️ **Success confirmation modal** after placing an order

│── script.js     # dynamic functionality (filtering, cart, modal logic)

## 🛒 User Flow

1. Search or filter products
2. Add items to cart
3. View items in sliding cart panel
4. Proceed to checkout modal
5. Enter user details
6. Confirm the order
7. See success message 🎉
